# Python/FastAPI/Jinja Usage

Using paste-assetgraph with Python FastAPI and Jinja2 templates.

## Installation

```bash
# Install paste-assetgraph binary
curl -L https://github.com/PasteStack/paste-assetgraph/releases/latest/download/paste-assetgraph-$(uname -s | tr '[:upper:]' '[:lower:]')-$(uname -m) -o /usr/local/bin/paste-assetgraph
chmod +x /usr/local/bin/paste-assetgraph

# Install Python dependencies
pip install fastapi uvicorn jinja2
```

## Configuration

**paste-surface.conf:**
```hocon
paste.surface.assets {
  source {
    js = "static/js"
    scss = "static/scss"
  }
  output {
    base = "static"
    js = ${paste.surface.assets.output.base}"/js"
    css = ${paste.surface.assets.output.base}"/css"
  }
  manifest = ${paste.surface.assets.output.base}"/manifest.json"
}
```

## Manifest Reader

**app/manifest.py:**
```python
import json
from pathlib import Path
from typing import Optional

class Manifest:
    def __init__(self, path: str):
        with open(path) as f:
            data = json.load(f)
        self.version = data["version"]
        self.assets = data["assets"]
    
    def resolve(self, source_path: str, debug: bool = False) -> Optional[str]:
        """Resolve source path to versioned output path."""
        entry = self.assets.get(source_path)
        if not entry:
            return None
        return entry["source"] if debug else entry["output"]
    
    def jam_url(self, modules: list[str], debug: bool = False) -> str:
        """Generate JAM URL for bundled modules."""
        # Find latest timestamp for this group
        latest_ts = 0
        module_versions = []
        
        for m in modules:
            key = f"js/{m.replace('.', '/')}.js"
            entry = self.assets.get(key)
            if entry:
                module_versions.append(f"{m}+v{entry['version']}.0")
                ts = int(entry.get("timestamp", 0))
                if ts > latest_ts:
                    latest_ts = ts
        
        group_ts = str(latest_ts) if latest_ts > 0 else self.version
        suffix = ".js" if debug else ".min.js"
        
        return f"/paste/{group_ts}/{','.join(module_versions)}{suffix}"
    
    def jam_css_url(self, modules: list[str], debug: bool = False) -> str:
        """Generate JAM URL for CSS modules."""
        latest_ts = 0
        module_versions = []
        
        for m in modules:
            key = f"css/{m.replace('.', '/')}.css"
            entry = self.assets.get(key)
            if entry:
                module_versions.append(f"{m}+v{entry['version']}.0")
                ts = int(entry.get("timestamp", 0))
                if ts > latest_ts:
                    latest_ts = ts
        
        group_ts = str(latest_ts) if latest_ts > 0 else self.version
        suffix = ".css" if debug else ".min.css"
        
        return f"/paste/{group_ts}/{','.join(module_versions)}{suffix}"
```

## FastAPI App

**app/main.py:**
```python
from fastapi import FastAPI, Request
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates
from .manifest import Manifest

app = FastAPI()

# Load manifest
manifest = Manifest("static/manifest.json")
DEBUG = False  # Set via environment

# Mount static files
app.mount("/static", StaticFiles(directory="static"), name="static")

# Setup Jinja2
templates = Jinja2Templates(directory="templates")

# Add manifest helpers to templates
templates.env.globals["asset"] = lambda path: manifest.resolve(path, DEBUG)
templates.env.globals["jam_js"] = lambda modules: manifest.jam_url(modules, DEBUG)
templates.env.globals["jam_css"] = lambda modules: manifest.jam_css_url(modules, DEBUG)
templates.env.globals["debug"] = DEBUG

@app.get("/")
async def home(request: Request):
    return templates.TemplateResponse("home.html", {
        "request": request,
        "title": "My Site"
    })
```

## Jinja Templates

**templates/base.html:**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>{{ title }}</title>
    
    {# CSS includes #}
    <link rel="stylesheet" href="{{ jam_css(['base.responsive', 'common.ui.heroscroll']) }}">
    
    {% block head %}{% endblock %}
</head>
<body>
    {% block content %}{% endblock %}
    
    {# JS includes with paste.define bootstrap #}
    {% set js_modules = ['paste.dom', 'paste.event', 'paste.ui.heroscroll'] %}
    <script type="text/javascript">
    (function(d,r){
        {% for m in js_modules %}d('{{ m }}').isLoading={% endfor %}!0;
        r('{{ jam_js(js_modules) }}');
    })(paste.define,paste.require);
    </script>
    
    {% block scripts %}{% endblock %}
</body>
</html>
```

**templates/home.html:**

## Build & Run

```bash
# Build assets
paste-assetgraph build

# Run dev server
uvicorn app.main:app --reload

# Production
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Watch Mode

```bash
# Terminal 1: Watch assets
paste-assetgraph watch

# Terminal 2: Run dev server
uvicorn app.main:app --reload
```
