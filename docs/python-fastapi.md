# Python/FastAPI/Jinja Usage

Using paste-assetgraph with Python FastAPI and Jinja2 templates.

The `paste-assetgraph` Python package is a thin loader for the Rust shared
library: all tag, URL and combo logic lives in the library. `Paste` calls
`paste_render` and `paste_combo` in-process through `ctypes` with your
manifest and output paths. The package
imports no web framework — it works the same from FastAPI, Flask, or Jinja.

## Installation

```bash
pip install paste-assetgraph    # the wheel ships the shared library under native-lib/

# Web stack
pip install fastapi uvicorn jinja2    # requires Python 3.9+
```

`resolve_library()` looks up `PASTE_ASSETGRAPH_LIB` first, then the bundled
`native-lib/{platform}` copy — a set-but-invalid override raises rather than
falling through.

## Configuration

**paste-surface.conf:**
```hocon
source.dirs = ["assets/js", "assets/scss"]
output.base = "static"
output.js = "static/js"
output.css = "static/css"
manifest = "static/manifest.json"
```

Each `source.dirs` root is walked recursively and classified by extension —
one directory may hold `.js`, `.scss` and `.css` together. With
`output.layout = "beside-source"` each file instead compiles into an
`output.build-dir-name` directory (default `_paste_build`) beside its source
and every manifest output is project-relative, so `Paste(...)` then takes the
project root as its output base rather than `static`.

## FastAPI App

**app/main.py:**
```python
from fastapi import FastAPI, Request
from fastapi.responses import Response
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates
from paste_assetgraph import Paste

app = FastAPI()

# The wrapper holds the manifest/output paths and the loaded library
paste = Paste("static/manifest.json", "static")

# Mount static files
app.mount("/static", StaticFiles(directory="static"), name="static")

templates = Jinja2Templates(directory="templates")

# Combo endpoint under paste.base_path ("/paste" by default): forward the
# raw request path — still percent-encoded, which the route's decoded `path`
# parameter is not — plus the raw query, and return the library's response
# untouched.
@app.get("/paste/{path:path}")
def combo(path: str, request: Request):   # sync def: FastAPI runs it in its threadpool
    path_and_query = request.scope["raw_path"].decode("ascii")
    if request.url.query:
        path_and_query += f"?{request.url.query}"
    r = paste.combo(path_and_query)   # in-process library call
    headers = {"Cache-Control": r.cache_control}
    if r.location is not None:
        headers["Location"] = r.location
    return Response(
        content=r.body,
        status_code=r.status,
        media_type=r.content_type,
        headers=headers,
    )

@app.get("/")
def home(request: Request):   # the template's dumps call the library
    return templates.TemplateResponse("home.html", {
        "request": request,
        "title": "My Site",
        "page": paste.page(),          # one PastePage per render
    })
```

`paste.combo()` calls the library synchronously — call it from a sync `def`
endpoint or `run_in_threadpool` so it does not block the event loop. The
wrapper adds no cache of its own: every call reaches the library, which
keeps a bounded manifest cache that reloads when the manifest file changes.

The response passes through the library's contract: each `+vN` in a versioned
URL is served exactly — the current version or a retained history version —
and under the default `jam.hash-urls` policy carries the version's full
content hash (`-h{hash}`), which a request must match exactly or get a
`no-cache` 404; successful versioned responses get
`public, max-age=31536000`; a non-canonical versioned URL (a stale
stamp, an unsorted list, an unpinned name, a non-numeric segment) is a 302
whose `location` names the canonical URL; a version the manifest cannot
serve, an unresolvable module, or a stamp newer than the manifest knows is a
`no-cache` 404, never a partial group.

## Jinja Templates

`page.jam(css=[...], js=[...])` records a group and returns `""`; the dumps
emit the markup — mark them `| safe`.

**templates/base.html:**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>{{ title }}</title>

    {{ page.jam(css=['base.responsive', 'common.ui.heroscroll'],
                js=['paste.dom', 'paste.event', 'paste.ui.heroscroll']) }}
    {{ page.dump_css() | safe }}

    {% block head %}{% endblock %}
</head>
<body>
    {% block content %}{% endblock %}

    {{ page.dump_js() | safe }}

    {% block scripts %}{% endblock %}
</body>
</html>
```

**templates/home.html:**
```html
{% extends "base.html" %}

{% block content %}
<section data-paste-hero="main" data-paste-parallax="true">
    <h1>Welcome</h1>
</section>

<main class="paste-container">
    <p>Content here</p>
</main>
{% endblock %}
```

The dumps emit the real markup: an inlined runtime once per page, exact-group
loader URLs with `isLoading` marks, `<link>`/inline `<style>` for CSS, and
threshold-based inline `<script>` groups.

## Build & Run

```bash
# Build assets
paste-assetgraph build

# Run dev server
uvicorn app.main:app --reload

# Production
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Watch Mode

```bash
# Terminal 1: Watch assets
paste-assetgraph watch

# Terminal 2: Run dev server
uvicorn app.main:app --reload
```
